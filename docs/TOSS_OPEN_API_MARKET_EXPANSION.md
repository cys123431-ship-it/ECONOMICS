# 토스증권 Open API 시장정보 확장

검토·구현일: 2026-08-24  
대상 버전: ECONOMICS Radar v0.6.0

## 결론

토스증권 Open API는 계좌번호 없이 OAuth2 액세스 토큰만으로 한국·미국 시장의 공개 시세·시장정보를 상당히 넓게 제공합니다. v0.6.0은 개인 계좌와 주문을 건드리지 않고 다음 정보를 대시보드에 반영합니다.

| 공식 API | 반영 정보 | 기본 갱신 |
|---|---|---:|
| `GET /api/v1/market-indicators/prices` | KOSPI·KOSDAQ, 한국 국채 2·3·5·10·20·30년 수익률 | 30초 |
| `GET /api/v1/exchange-rate` | USD/KRW 참고 매수환율, 매매기준율, 스프레드, 유효시간 | 30초 |
| `GET /api/v1/market-indicators/{symbol}/candles` | KOSPI·KOSDAQ 30일 일봉 OHLCV | 5분 |
| `GET /api/v1/market-indicators/{symbol}/investor-trading` | 개인·외국인·기관·기관 7개 세부 분류·기타법인 매수/매도대금 | 5분 |
| `GET /api/v1/market-calendar/KR` | KRX+NXT 프리·정규·애프터마켓 운영시간 | 5분 |
| `GET /api/v1/market-calendar/US` | 미국 데이·프리·정규·애프터마켓 운영시간 | 5분 |
| `GET /api/v1/rankings` | 한국·미국 거래대금·급상승·급하락 TOP 10 | 5분 |
| `GET /api/v1/stocks` | 랭킹 종목명·시장·상품유형 | 랭킹 갱신 시 |

공식 원문은 [토스증권 API 가이드](https://developers.tossinvest.com/docs)와 [OpenAPI 1.2.14 명세](https://openapi.tossinvest.com/openapi-docs/latest/openapi.json)를 기준으로 했습니다. 명세는 시장지표 8종의 단위, 환율 1분 갱신, 수급 잠정치의 `updatedAt`, 장 캘린더 세션, 랭킹 기간·기준가 의미를 각각 정의합니다.

## 데이터 해석 원칙

- 한국 국채 `lastPrice`는 채권 가격이 아니라 연 수익률 `%`입니다.
- 환율 `midRate`는 참고 매매기준율이고 `rate`는 참고 매수환율입니다. 실제 주문 환율로 간주하지 않습니다.
- 시장 수급은 매수액과 매도액 원본을 보존하고 `순매수 = 매수 - 매도`만 파생합니다. 외국인은 등록·미등록 외국인 전체 합계입니다.
- 당일 시장 수급은 장 종료 전 잠정치일 수 있어 원본 `updatedAt`을 함께 표시합니다.
- 급상승·급하락 `changeRate`는 선택 기간 시작 기준가 대비이고, 거래대금 랭킹 등락률은 전일 기준가 대비입니다.
- KRX+NXT 통합 캘린더는 시간외종가·시간외단일가를 포함하지 않습니다.
- 토스 실시간 지수의 원본 시각이 KRX 공식 EOD보다 새로울 때만 현재지수를 덮어씁니다. 키 미설정이나 장애 때는 KRX EOD로 자동 대체합니다.

## 저장과 장애 대응

- 지수·국채·환율 현재값은 덮어쓰기형 `live_quotes`에 저장해 불필요한 30초 이력 폭증을 막습니다.
- 일봉과 일별 수급은 원본 일자·갱신시각·개정 ID를 가진 시계열로 저장합니다.
- 시장지표 현재가의 nullable `timestamp`가 null이면 같은 값의 최신 공식 캔들만 시각 근거로 사용합니다. KOSPI·KOSDAQ은 1분봉, 국채는 일봉을 사용하며 값이 다르면 시각을 만들지 않습니다.
- 장 캘린더·랭킹·수급 원본 응답은 최신 시장 스냅샷으로 별도 저장합니다. 일부 API가 실패해도 마지막 정상 패널은 유지합니다.
- 액세스 토큰은 만료 전까지 메모리에서 재사용하고 401은 한 번 재발급합니다. 429는 공식 `Retry-After`를 최대 3초 범위에서 한 번 준수하며, 랭킹 6개 요청은 그룹 한도에 맞춰 간격을 둡니다.
- 오류에는 client secret·액세스 토큰·전체 인증 요청 본문을 포함하지 않습니다.

## 의도적으로 제외한 범위

- 계좌 목록, 보유주식, 잔고, 주문 내역은 이번 시장 대시보드에 필요하지 않아 호출하지 않습니다.
- 주문 생성·정정·취소와 조건주문은 읽기 전용 감시기의 범위를 벗어나므로 구현하지 않습니다.
- 개별 종목 전체 유니버스의 호가·체결·공매도·신용·대차를 무차별 수집하지 않습니다. 랭킹에 등장한 종목의 기본 참조정보만 조회합니다.
- 웹소켓은 개별 주식 체결·호가용이며 KOSPI·KOSDAQ 시장지표 스트림은 공식 스펙에 없으므로, 시장지표는 30초 REST 폴링을 유지합니다.

## 활성화 조건

`E:\EconomicsRadar\.env`에 다음 두 값을 입력하고 토스증권 Open API 설정에서 이 노트북의 공인 IP를 허용해야 합니다.

```env
TOSSINVEST_CLIENT_ID=
TOSSINVEST_CLIENT_SECRET=
```

개인 계좌번호 환경변수는 필요하지 않습니다. 키가 없으면 화면에 활성화 안내를 표시하고 기존 공식 데이터 경로를 계속 사용합니다.
